# NEXUS//04

A space mission design game and learning site built for the NASA Space Apps Challenge 2026 (challenge: Space Mission Design Game) by team NEXUS//04: Sneha, Karishma, Kshitij and Anttariksha.

Live site: https://kshitij7737.github.io/astra-nexus/

## AI disclosure
The mission research (science facts, instrument choices, values and sources) was done by the team. The website code (HTML, CSS, JavaScript and shaders), the 3D scenes and the chapter films were generated with AI tools and then reviewed, tested and edited by the team. AI-generated visuals are marked with a visible "AI-generated" label on the site and in the films. No NASA logos are used. Sources for every fact are listed on sources.html.
